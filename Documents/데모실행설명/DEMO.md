# 콩닥식탁 시연 가이드

## 🎯 시연 목표
신장 투석 환자를 위한 AI 기반 맞춤형 식단 관리 챗봇 기능 시연

## 📋 사전 준비

### 1. 환경 변수 설정
```bash
# .env 파일 생성
cp .env.example .env

# .env 파일 편집 (필수!)
# OPENAI_API_KEY=your-openai-api-key-here
# DB_PASSWORD=kongdak2024
```

### 2. Docker 컨테이너 실행
```bash
# Docker Compose로 전체 서비스 실행
docker-compose up -d

# 서비스 상태 확인
docker-compose ps

# 로그 확인
docker-compose logs -f
```

### 3. 서비스 접속 확인
- **백엔드 API 문서**: http://localhost:8000/api/docs
- **프론트엔드 Streamlit**: http://localhost:8501
- **PostgreSQL**: localhost:5432

## 🚀 시연 시나리오

### 시나리오 1: 기본 채팅 및 영양 분석 (3분)

**1단계: 떡볶이 질문**
```
사용자 입력: "떡볶이 먹어도 될까요?"
```

**예상 결과:**
- 재료 자동 추출 (떡, 고추장, 어묵, 파)
- 영양 분석 결과 표시
  - 나트륨: 1,837mg (초과 ❌)
  - 칼륨: 235mg (안전 ✅)
  - 인: 220mg (안전 ✅)
  - 단백질: 16g (안전 ✅)
- 위험도: 🔴 높음
- 대체 레시피 제안
- 조리 팁 제공

**2단계: 영양 분석 탭 확인**
- 도넛 차트: 영양소 구성 비율
- 바 차트: 기준치 대비 영양소 함량
- 발견된 재료 / 정보 없는 재료 표시

---

### 시나리오 2: 퀴즈 기능 시연 (2분)

**1단계: 퀴즈 제안**
- 위험도가 높은 음식을 질문하면 "📝 퀴즈로 복습하기" 버튼 표시

**2단계: 퀴즈 풀기**
```
예상 문제:
1. 신장 투석 환자가 1끼에 섭취 가능한 나트륨 양은? (객관식)
2. 떡볶이의 나트륨을 줄이는 방법은? (단답형)
3. 고추장은 고칼륨 식품이다 (O/X)
```

**3단계: 결과 확인**
- 정답/오답 즉시 피드백
- 해설 표시
- 정답률 계산

---

### 시나리오 3: 자료 추천 시연 (1분)

**1단계: 자료 검색**

검색어: "저염식 레시피"

- 관련성 점수 표시 (⭐⭐⭐⭐⭐)

### 예상 질문 및 답변

**Q1: RAG가 없으면 어떻게 되나요?**
> "RAG가 없으면 LLM이 일반적인 지식만으로 답변하게 되어,
> 식약처나 대한신장학회의 공식 가이드라인을 반영하지 못합니다.
> RAG를 통해 신뢰할 수 있는 의료 정보를 제공할 수 있습니다."

**Q2: 영양 데이터는 어디서 가져오나요?**
> "국가표준식품성분표를 기반으로 PostgreSQL 데이터베이스에 저장했습니다.
> 현재는 15개 샘플 데이터이지만, 확장 가능한 구조로 설계했습니다."

**Q3: 왜 Streamlit을 선택했나요?**
> "빠른 프로토타입 개발과 데이터 시각화에 최적화된 프레임워크이기 때문입니다.
> Python 기반이라 백엔드와 통합이 용이하고, Plotly를 통한 시각화도 간편합니다."

**Q4: 실제 서비스 배포 계획은?**
> "현재는 Docker Compose로 로컬 배포 가능하며,
> AWS ECS 또는 Google Cloud Run을 통한 클라우드 배포를 계획 중입니다."
